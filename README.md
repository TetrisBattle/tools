# Stay Awake - Keep Your Computer from Sleeping

This script keeps your computer awake by running quietly in the background.
It works by toggling NumLock every 4 minutes, which tricks Windows into thinking someone is using the computer.

---

## How to Run It

1. **Right-click** the file called **stay-awake.ps1**
2. In the menu that appears, click **"Run with PowerShell"**
3. A PowerShell window will appear and show the message:
   > Stay Awake script started

   **This means it is working!**
4. Leave that window open. As long as it is open, your computer will not go to sleep.

---

## How to Stop It

Simply **close the PowerShell window** by clicking the **X** in the top-right corner.
